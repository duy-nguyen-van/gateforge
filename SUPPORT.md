# Support

## How to get help

| Need | Where |
|------|--------|
| Bug | [Bug report](https://github.com/duy-nguyen-van/gateforge/issues/new?template=bug_report.md) |
| Feature idea | [Feature request](https://github.com/duy-nguyen-van/gateforge/issues/new?template=feature_request.md) |
| Security issue | [SECURITY.md](SECURITY.md) — private advisory only |
| Usage question | [GitHub Discussions](https://github.com/duy-nguyen-van/gateforge/discussions) (if enabled), otherwise an issue with clear reproduction steps |
| Contribute a fix | [CONTRIBUTING.md](CONTRIBUTING.md) |

## What maintainers can and cannot do

GateForge IAM is self-hosted. Maintainers help with project bugs, docs, and contributions. They do not operate your deployment, rotate your keys, or provide paid SLA support unless you arrange that separately.

## Response expectations

Best-effort on a volunteer schedule. Security reports follow the timelines in [SECURITY.md](SECURITY.md).
